# Overleaf resume skill suite

This project contains composable Codex skills for creating and maintaining a truthful, tailored resume in an Overleaf project.

| Skill | Use it for |
| --- | --- |
| `resume-content-strategy` | Turning a career history into a selective, evidence-based master resume. |
| `resume-job-tailoring` | Producing an honest role-specific resume from a job description. |
| `overleaf-resume-authoring` | Editing or structuring an Overleaf/LaTeX resume project. |
| `resume-project-writing` | Converting projects into concise, outcome-focused entries. |
| `resume-quality-review` | Auditing factual accuracy, relevance, ATS readability, and rendered PDF quality. |

The skills deliberately separate content decisions, job tailoring, LaTeX authoring, and review so that a reviewer can inspect a resume without silently rewriting its claims.

To use them in Codex, copy the desired skill folders into your Codex skills directory, preserving each folder's contents. They can also be invoked from this project by name where local skill discovery is supported.
